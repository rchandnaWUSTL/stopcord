# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub: open the [Security tab](https://github.com/rchandnaWUSTL/stopcord/security) and choose "Report a vulnerability". Don't open a public issue.

Useful things to include: what you found, how to reproduce it, and what an attacker gains. A way around the policy gate, a log edit that `stopcord verify` doesn't catch, or a way for an agent to reach the log or policy through the gateway are all in scope.

I'll reply within a few days.

## Supported versions

Only the latest commit on `main` is supported while the project is at 0.x.
