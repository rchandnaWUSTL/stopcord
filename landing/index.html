What you get

rule

Rules you write, enforced every time

Allow or block files, commands and websites in a short config file. Ordinary code checks the rules, so the same action always gets the same answer. The check and log write take about 0.2 ms per call.

receipt_long

A record you can check

Every attempt, allowed or blocked, goes into a log. Each entry is linked to the one before it, so if anyone edits a line later, stopcord verify points to it.

front_hand

A stop button

Stop the agent mid-task from the console or the terminal. Its access is cut off right away and its next action fails.

compare_arrows

What it said vs. what it did

After each run, a report puts the agent's own summary beside the log and lists the blocked actions it didn't mention.

Already using Claude Code's permission rules or hooks?

Keep them. StopCord adds a record you can verify later, a way to stop a run in progress, a report on what the agent left out, and one set of rules for every agent you use.

For engineers using agents

  • Add it to Claude Code, Cursor or any MCP agent with one config entry.
  • Turn off the agent's built-in file, shell and web tools so its actions go through StopCord. This is most of the setup work.
  • Start from the included rules, and watch every action live in a local console.
# in your agent's MCP config
"stopcord": {
  "command": "uvx",
  "args": ["--from", "git+https://github.com/rchandnaWUSTL/stopcord@v0.1.0",
           "stopcord", "gateway",
           "--policy", "policy.yaml", "--workspace", "."]
}

What it won't do

This makes an agent's actions observable and containable. It does not make the agent aligned, and it does not stop harm inside what the policy allows.

It can't fix bad rules

If your rules allow something harmful, the agent can do it.

It only sees what goes through it

Turn off your agent's built-in shell and file tools, or it can go around StopCord.

The record shows edits, it doesn't prevent them

Someone who controls the machine could rewrite the whole log. Changing part of it gets caught by stopcord verify.
